Good navigation helps readers find a page without search. Doxa gives you three levels.

| Level | Where it appears | Example in this site |
| ----- | ---------------- | -------------------- |
| Section | Tabs at the top of the page | Documentation, API Reference |
| Group | Headings in the sidebar | Get Started, Writing Content |
| Page | Items in the sidebar | Quickstart, Code blocks |

## Change the navigation

In the dashboard, open **Site settings** and then **Navigation**. There you can:

- Add, rename, and remove sections.
- Move pages between groups.
- Set an icon or a badge on a page. The **Diagrams and file trees** page in this site has a **New** badge.

## Tips for a clear sidebar

1. Put the pages for new readers in the first group.
2. Keep each group to about seven pages or fewer.
3. Use short page titles. The sidebar has little space.

<Note title="Site appearance">
  Change the colors, logo, and fonts of your site in **Site settings** and then **Appearance**.
