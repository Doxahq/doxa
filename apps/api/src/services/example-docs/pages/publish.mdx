Your site is live from the moment that you create the project. Each time that you publish, Doxa makes a new version of the site.

## Publish a change

<Step>
  <StepItem title="Edit pages">
    Make your changes in the editor. Doxa saves them as a draft.
  </StepItem>

  <StepItem title="Review the draft">
    Use **Split** mode to preview each page before you publish.
  </StepItem>

  <StepItem title="Publish">
    Click **Publish**. Readers see the new version in a few seconds.
  </StepItem>
</Step>

## Write docs from your code with AI

Doxa can read your source code and write the documentation for you. This feature needs a GitHub repository.

<Step>
  <StepItem title="Connect a repository">
    Open the project overview and click **Connect repository**. Install the Doxa GitHub App, then select a repository.
  </StepItem>

  <StepItem title="Run a generation">
    Click **Generate docs**. Doxa reads the repository and writes a full documentation site.
  </StepItem>
</Step>

<Note title="Generation replaces this example" type="warning">
  The first AI generation replaces all the pages of this example site with pages written from your code.
</Note>
