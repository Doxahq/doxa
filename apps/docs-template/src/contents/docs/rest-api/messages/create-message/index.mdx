Creates a message record and returns the stored message with its generated identifier and creation timestamp.

The docs site answers the `baseUrl` on this page, so **Try it** returns a real response without depending on an external service. A production endpoint points at its own API origin.

<ApiEndpoint method="POST" path="/v1/messages" baseUrl="/api/echo">

<ApiRequestExample client="curl" lang="bash" label="Create a message">

```bash
curl -X POST "https://httpbin.org/anything/v1/messages" \
  -H "Authorization: Bearer doxa_test_token" \
  -H "Content-Type: application/json" \
  -d '{"body":"Ship reference docs as a separate section."}'
```

<ApiRequestExample client="go" lang="go" label="Create a message">

```go
package main

import (
	"bytes"
	"fmt"
	"io"
	"net/http"
)

func main() {
	url := "https://httpbin.org/anything/v1/messages"
	payload := []byte(`{"body":"Ship reference docs as a separate section."}`)

	req, _ := http.NewRequest("POST", url, bytes.NewBuffer(payload))
	req.Header.Set("Authorization", "Bearer doxa_test_token")
	req.Header.Set("Content-Type", "application/json")

	res, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	body, _ := io.ReadAll(res.Body)
	fmt.Println(string(body))
}
```

<ApiParams title="Authentication">
  <ApiParam name="Authorization" type="bearer" location="header" required>
    Bearer token for the calling account. The playground keeps this value for
    the browser session only.
  </ApiParam>
</ApiParams>

<ApiParams title="Body" detail="application/json">
  <ApiParam name="body" type="string" location="body" required>
    Message text. Must not be empty.
  </ApiParam>
  <ApiParam name="idempotencyKey" type="string" location="body">
    Optional caller-supplied key. A repeated key returns the first message
    instead of creating a second one.
  </ApiParam>
</ApiParams>

<ApiParams title="Response" detail="application/json">
  <ApiParam name="id" type="string" location="response" required>
    Stable message identifier.
  </ApiParam>
  <ApiParam name="body" type="string" location="response" required>
    The stored message text.
  </ApiParam>
  <ApiParam name="createdAt" type="string" location="response" required>
    ISO timestamp for when the message was created.
  </ApiParam>
</ApiParams>

## Errors

| Status | Code              | Meaning                                        |
| ------ | ----------------- | ---------------------------------------------- |
| `400`  | `invalid_request` | The JSON body is malformed or `body` is empty. |
| `401`  | `unauthorized`    | The bearer token is missing or invalid.        |
| `429`  | `rate_limited`    | The caller sent too many requests.             |
