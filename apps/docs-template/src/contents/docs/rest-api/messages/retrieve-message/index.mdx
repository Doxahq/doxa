Retrieves a message record by its identifier.

This page demonstrates a path parameter in the playground. **Try it** substitutes the `id` you enter into the request path before it sends the request.

<ApiEndpoint method="GET" path="/v1/messages/{id}" baseUrl="/api/echo">

<ApiRequestExample client="go" lang="go" label="Retrieve a message">

```go
package main

import (
	"fmt"
	"io"
	"net/http"
)

func main() {
	url := "https://httpbin.org/anything/v1/messages/msg_01JY8Z7A3Q8M9K2W4N6P0R1S2T"

	req, _ := http.NewRequest("GET", url, nil)
	req.Header.Set("Authorization", "Bearer doxa_test_token")

	res, err := http.DefaultClient.Do(req)
	if err != nil {
		panic(err)
	}
	defer res.Body.Close()

	body, _ := io.ReadAll(res.Body)
	fmt.Println(string(body))
}
```

## Errors

| Status | Code           | Meaning                                  |
| ------ | -------------- | ---------------------------------------- |
| `401`  | `unauthorized` | The bearer token is missing or invalid.  |
| `404`  | `not_found`    | No message exists for the supplied `id`. |
| `429`  | `rate_limited` | The caller sent too many requests.       |
