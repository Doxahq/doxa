Follow these steps to run the site.

<Step>
  <StepItem title="Install dependencies">

```bash
pnpm install
```

  </StepItem>

  <StepItem title="Start the dev server">

```bash
pnpm dev
```

  </StepItem>

  <StepItem title="Open the site">
    Open `http://localhost:3000` in the browser.
  </StepItem>
</Step>

## Choose a deployment target
